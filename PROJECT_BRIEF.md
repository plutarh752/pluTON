## Контекст и цель

Я торгую коллекционными Telegram-подарками (NFT на блокчейне TON) — модели типа Mood Pack, Plush Pepe и т.д. У каждого подарка 4 оси атрибутов: Model, Backdrop, Symbol, Number, каждая со своим процентом редкости. Флиппинг работает так: купить лот с редкими атрибутами близко к floor коллекции → выставить дороже → продать.

Мне нужен **веб-сайт (не Telegram-бот)**, который по нажатию кнопки "Скан":
1. Собирает актуальные лоты и floor'ы с источников
2. Сохраняет снапшот в базу
3. Считает Deal Score для каждого лота
4. Показывает мне таблицу с самыми выгодными лотами и калькулятором реальной прибыли

**Никакого фонового поллинга. Только по клику.** Между сканами сайт работает как read-only витрина из БД.

## Ключевые бизнес-правила (не игнорировать)

1. **Реальная прибыль ≠ номинал в звёздах.** Формула вывода:
```
   real_usd = price_stars × 0.8 × 0.013
```
   (0.8 — комиссия Telegram, 0.013 — курс stars→USD, оба хранятся в `settings` и настраиваются в UI). Плюс cooldown 21 день на вывод.

2. **Deal Score учитывает ликвидность, а не только "дешевизну":**
```
   deal_score = undervaluation_pct × liquidity_factor × freshness_factor
```
   где:
   - `undervaluation_pct = (expected_price − listing_price) / expected_price`
   - `liquidity_factor` = число реальных продаж этой модели за последние 7 дней (нормализовано)
   - `freshness_factor` = штраф за старые лоты, висящие давно

3. **Expected price для MVP — эвристика, не ML:**
```
   expected_price = collection_floor × (1 + Σ rarity_bonus)
   rarity_bonus_i = (100 / attribute_rarity_pct_i) × weight_i
```
   Веса (weight) захардкодить сначала (например Backdrop=0.5, Symbol=0.3, Number=0.2), но вынести в settings для крутки.

4. **Все цены в UI показываются парой:** `⭐ 7899 (~$82.15 net)`. Голые звёзды — запрещены везде.

5. **Хранить дельты, не полные снапшоты.** При скане писать только: новые лоты, изменившие цену, исчезнувшие. Раз в 24 часа — агрегированный daily aggregate для истории.

## Стек (не менять без причины)

- **Frontend:** Next.js 14 (App Router) + Tailwind + shadcn/ui + recharts
- **Backend для скрейпа/аналитики:** отдельный Python-сервис (FastAPI), поскольку понадобится pandas для агрегаций и, возможно, потом scikit-learn
- **База:** PostgreSQL (для локальной разработки — Docker Compose, для продакшена — Neon или Railway)
- **Оркестрация локально:** Docker Compose (postgres + backend + frontend)
- **Деплой:** Vercel для фронта, Railway для Python-бэка и БД (обсудим отдельно)

## Источники данных

Для MVP использовать **только один источник**: TON blockchain через `tonapi.io` (у них открытая документация и бесплатный тир). Это позволит получить:
- Историю трансферов NFT в коллекциях подарков
- Атрибуты каждого NFT
- Владельцев

Маркетплейсы (Tonnel, Portals, MRKT) во V2 — там нужен реверс TG Mini App, что нетривиально.

**Экран 5: Settings**

- Cooldown между сканами (default 15 min)
